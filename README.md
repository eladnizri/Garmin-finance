# 💤 דשבורד בריאות ושינה — Garmin

דשבורד אישי שמציג את נתוני השינה, הדופק, הסטרס והפעילות שלך מ-Garmin Connect.
הנתונים נמשכים **אוטומטית פעם ביום** על ידי GitHub Actions, נשמרים בקובץ
`data/health.json`, והדשבורד (אתר סטטי ב-GitHub Pages) מציג אותם — הכל **100% חינמי**,
בלי שרתים ובלי שירותים חיצוניים.

```
[Garmin Connect] ──(GitHub Action, פעם ביום)──> [data/health.json] ──> [הדשבורד ב-GitHub Pages]
```

## 🚀 התקנה — 3 צעדים (הכל מהטלפון)

### צעד 1: הוספת פרטי ההתחברות לגרמין (Secrets)

1. פתח את המאגר (repository) באתר GitHub בדפדפן של הטלפון.
2. עבור אל: **Settings ← Secrets and variables ← Actions ← New repository secret**.
3. צור **שני** סודות:
   - שם: `GARMIN_EMAIL` — ערך: האימייל של חשבון Garmin Connect שלך.
   - שם: `GARMIN_PASSWORD` — ערך: הסיסמה של חשבון Garmin Connect.

> הסודות מוצפנים על ידי GitHub, לא מופיעים בקוד ולא נראים לאף אחד — גם לא לך אחרי השמירה.

### צעד 2: הרצת סנכרון ראשונה

1. עבור ללשונית **Actions** במאגר.
2. בחר בצד את **Sync Garmin Data**.
3. לחץ **Run workflow ← Run workflow**.
4. המתן כ-2–3 דקות. בסיום, קובץ `data/health.json` יתמלא ב-30 הימים האחרונים.

מרגע זה הסנכרון ירוץ אוטומטית **כל יום סביב השעה 12:00 בצהריים (שעון ישראל)** וימשוך
את 7 הימים האחרונים (כך שגם אם השעון סונכרן באיחור — הנתונים יושלמו למחרת).

### צעד 3: הפעלת GitHub Pages

1. עבור אל: **Settings ← Pages**.
2. תחת **Build and deployment ← Source** בחר **Deploy from a branch**.
3. בחר את הענף הראשי (main) ותיקייה `/ (root)`, ולחץ **Save**.
4. אחרי כדקה הדשבורד יהיה זמין בכתובת:
   `https://<שם-המשתמש>.github.io/Garmin-finance/`

💡 **טיפ:** פתח את הכתובת בטלפון ובחר בדפדפן **"הוסף למסך הבית" (Add to Home Screen)** —
תקבל אייקון שנפתח כמו אפליקציה.

## 📊 מה יש באפליקציה

יש שני עמודים, עם ניווט ביניהם בראש המסך:

### עמוד 1 — דשבורד (`index.html`)
- **כרטיסיות KPI** — ממוצע שעות שינה, ציון שינה (Sleep Score), דופק מנוחה (RHR),
  שונות דופק (HRV), רמת מתח וצעדים — כולל חץ מגמה לעומת התקופה הקודמת.
- **גרפים** — שעות שינה מול קו יעד של 8 שעות, שלבי שינה (עמוקה/קלה/REM),
  דופק מנוחה, HRV, סטרס מול טווח Body Battery, וצעדים מול יעד 10,000.
- **סינון** — 7 ימים / 30 ימים / הכל. כל המדדים, הגרפים והטבלה מתעדכנים בלחיצה.
- **טבלת היסטוריה** — כל הנתונים היומיים, עם מיון בלחיצה על כותרת עמודה.

### עמוד 2 — ניתוח מקצועי (`analysis.html`)
- **מדד מוכנות** — הערכה כללית משוקללת (שינה + מתח + HRV + RHR) עם פירוט הגורמים.
- **כרטיס לכל מדד** — הסבר *מה המדד מודד*, *לאן הוא נע אצלך* בתקופה שנבחרה,
  *על מה שינוי כזה עשוי להשפיע* (ההסבר משתנה לפי כיוון העלייה/הירידה), וטיפים מעשיים.
- **הצלבות נתונים** — זיהוי קשרים אישיים בין המדדים (למשל: "בלילות שישנת יותר, דופק
  המנוחה נטה להיות נמוך יותר"), עם ציון עוצמת הקשר.

> ⚠️ הניתוח הוא כלי מעקב ומודעות עצמית, **לא ייעוץ רפואי**. מדדים כמו RHR ו-HRV אישיים
> מאוד — מה שחשוב הוא המגמה שלך לאורך זמן.

לפני הסנכרון הראשון שני העמודים מציגים **נתוני דמו** (עם באנר אזהרה), כדי שתוכל לראות
איך הכל נראה מיד.

### ייבוא ריצות עבר מהאייפון (אופציונלי)

הגרמין מספק רק את החלון שנמשך בסנכרון. כדי להאריך את גרף ההשתפרות אחורה,
אפשר לייבא ריצות מייצוא הבריאות של האייפון:

1. באייפון: **בריאות ← תמונת הפרופיל ← "ייצוא כל הנתונים"**. נוצר קובץ ZIP; חלץ אותו.
2. באפליקציה: **כרטיס הפרופיל ← "ייבוא ריצות עבר מהאייפון"**, ובחר את `export.xml`
   (לא `export_cda.xml`, ולא ה-ZIP עצמו).
3. הניתוח רץ במכשיר עצמו — הקובץ אינו נשלח לשום מקום. נקראות רק ריצות משנתיים
   האחרונות, וימים שכבר יש עליהם ריצת גרמין נשארים עם נתוני הגרמין המפורטים יותר.

הריצות נשמרות ב-`localStorage` של אותו מכשיר. כדי שיהיו זמינות בכל המכשירים,
לחץ על **"הורדת הקובץ לשמירה בריפו"** שמופיע בסיום, והעלה את הקובץ שהתקבל
ל-`data/runs_history.json`. הסנכרון היומי אינו נוגע בקובץ הזה.

### החלפת מקור הנתונים (אופציונלי)

בראש הקובץ `common.js` יש קבוע `DATA_URL`. ברירת המחדל היא `data/health.json`,
אבל אפשר להציב שם גם כתובת CSV ציבורית של Google Sheets — הקוד מזהה לבד אם
מדובר ב-JSON או ב-CSV. להפקת קישור כזה מ-Google Sheets:

1. פתח את הגיליון ← **File ← Share ← Publish to web**.
2. בחר את הלשונית הרצויה ופורמט **CSV**, ולחץ **Publish**.
3. העתק את הקישור והדבק אותו כערך של `DATA_URL` ב-`script.js`.

## ❓ פתרון תקלות

- **הסנכרון נכשל עם שגיאת התחברות** — ודא שהאימייל והסיסמה ב-Secrets נכונים.
  אם מופעל אצלך **אימות דו-שלבי (MFA)** בחשבון גרמין, ההתחברות האוטומטית תיכשל;
  אפשר לכבות MFA בהגדרות חשבון Garmin, או לפתוח Issue כאן כדי להוסיף תמיכה
  בזרימת טוקנים ידנית.
- **חסרים נתונים ליום מסוים** — כנראה שהשעון עוד לא סונכרן לאפליקציית Garmin
  Connect באותו בוקר. הסנכרון מושך כל יום את 7 הימים האחרונים, כך שהחוסר יושלם
  אוטומטית למחרת.
- **הדשבורד מציג נתוני דמו** — קובץ `data/health.json` עדיין ריק. הרץ את ה-Action
  ידנית (צעד 2) וודא שהסתיים בהצלחה (סימן ✓ ירוק).
- **הערה כללית** — משיכת הנתונים משתמשת בספריית `garminconnect` הפופולרית, שעובדת
  מול ממשק לא-רשמי של גרמין. אם גרמין ישנו משהו והסנכרון יישבר, בדרך כלל עדכון
  גרסת הספרייה ב-`scripts/requirements.txt` פותר את זה.
